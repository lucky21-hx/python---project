# Python Calculator

## Description
A command-line calculator built using Python that performs basic arithmetic operations. This project demonstrates fundamental programming concepts such as functions, loops, and error handling.

## Features
- Addition, Subtraction, Multiplication, Division
- Handles invalid input
- Prevents division by zero
- Interactive CLI interface

## Tech Stack
- Python 3

## How to Run
1. Install Python
2. Open terminal
3. Run:
   python calculator.py

## Example Output
Enter first number: 10  
Enter second number: 5  
Operation: +  
Result: 15
